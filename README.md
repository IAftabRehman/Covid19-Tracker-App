<h1>COVID-19 Tracker App</h1>

<p>A user-friendly mobile application developed using Flutter, aimed at providing accurate and real-time information on the COVID-19 pandemic. The app offers a clear and concise way to track global and country-specific COVID-19 statistics, including confirmed cases, recoveries, and deaths.</p>

<h2>Features</h2>
<ul>
<li>🌍 <strong>Global and Country-Specific Data</strong>: View real-time COVID-19 statistics for different countries.</li>
<li>📊 <strong>Detailed Insights</strong>: Track confirmed cases, recoveries, and deaths.</li>
<li>🔄 <strong>Live API Integration</strong>: Fetches the latest data from a reliable COVID-19 API.</li>
<li>🛠 <strong>Smooth UI with Flutter</strong>: Designed with a clean and modern user interface.</li>
<li>📅 <strong>Daily Updates</strong>: Ensures the latest pandemic information is displayed.</li>
</ul>

<h2>Installation</h2>
<ol>
<li>Clone the repository:
<pre><code>git clone https://github.com/IAftabRehman/covid19-tracker-flutter.git</code></pre>
</li>
<li>Navigate to the project directory:
<pre><code>cd covid19-tracker-flutter</code></pre>
</li>
<li>Install dependencies:
<pre><code>flutter pub get</code></pre>
</li>
<li>Run the app:
<pre><code>flutter run</code></pre>
</li>
</ol>

<h2>API Used</h2>
<p>This app fetches real-time COVID-19 data from:</p>
<ul>
<li><a href="https://disease.sh/v3/covid-19/historical/all?lastdays=all">Disease.sh API</a></li>
</ul>
